# 事件性双字动词白名单
# ════════════════════════════════════════════════════════════════
# 背景：
#   HanLP PKU/CTB/863 三套标签都不区分"事件动词"vs"介词性动词"vs"通用
#   动作动词"——处于/上演/推开/相信/抵达/回应 全部标成 v。
#
#   segmenter 里把"双字 v 进 verb_pending"的机制关掉后（避免 处于奥德赛
#   时期/上演短剧圈 等噪声），少数真正的事件动词也会丢失（零封日本/暴
#   发疫情/抵达北京）。
#
# 本文件作用：
#   列出明确"事件性"的双字动词。segmenter 遇到这些词时，
#   **强制按 vn（名动词）处理**——直接进 buf 当短语一部分，不作切点。
#
# 添加规则：
#   1) 必须是双字、纯中文
#   2) 出现在标题里时几乎总是"事件结果"或"动作主体"
#      （特朗普抵达北京 / 国乒夺冠 / 公司公布财报）
#   3) 不要加"通用动作动词"（看到/找到/想到/听到/接到）
#   4) 不要加"心理/观点动词"（相信/觉得/认为/希望/可能）
#   5) 不要加"介词性动词"（处于/关于/对于/用来/来自/写给）
#   6) 不要加"程度/方式副词性"（再次/几乎/大概）
#
# 修改后下次进程启动会自动加载（无需特殊操作）。
# ════════════════════════════════════════════════════════════════
